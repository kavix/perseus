# MEDUSA CTF - Customization Guide

## How to Change Flag and Credentials

### Quick Summary

**To change the flag and/or credentials, you need to:**
1. Update the database with new username/password
2. Generate new encrypted flag bytes
3. Update `database_helper.dart` with the new encrypted bytes

---

## Method 1: Using the Helper Scripts (Recommended)

### Step 1: Manage Database Users

```bash
cd tools
python3 manage_database.py
```

**Interactive Menu Options:**
- `1` - List all users
- `2` - Add new user
- `3` - Update user password
- `4` - Delete user
- `5` - Clear all users

**Command-Line Usage:**
```bash
# List all users
python3 manage_database.py list

# Add a new user
python3 manage_database.py add newuser newpass123

# Update password
python3 manage_database.py update admin new_password

# Delete a user
python3 manage_database.py delete olduser
```

### Step 2: Generate Encrypted Flag

After changing credentials, generate the new encrypted flag:

```bash
cd tools
python3 generate_encrypted_flag.py
```

**Example:**
```
Enter credentials and flag:
Username: admin
Password: new_password_here
Plaintext Flag: MEDUSA{your_new_flag_here}

Copy this into database_helper.dart:
============================================================
final List<int> encryptedFlag = [
  0x1a, 0x2b, 0x3c, 0x4d, ...
];
============================================================
```

### Step 3: Update database_helper.dart

1. Open `lib/database_helper.dart`
2. Find the `encryptedFlag` list (around line 15)
3. Replace with the output from Step 2

## Method 3: Programmatic (Python)

```python
import sqlite3
import hashlib

# Connect to database
conn = sqlite3.connect('assets/medusa.db')
cursor = conn.cursor()

# Add new user
cursor.execute(
    "INSERT INTO credentials (username, password) VALUES (?, ?)",
    ('myuser', 'mypass')
)

# Update existing user
cursor.execute(
    "UPDATE credentials SET password = ? WHERE username = ?",
    ('new_password', 'admin')
)

# Commit changes
conn.commit()
conn.close()

# Generate encrypted flag
username = 'myuser'
password = 'mypass'
flag = 'MEDUSA{my_custom_flag}'

key = hashlib.sha256((username + password).encode()).digest()
flag_bytes = flag.encode('utf-8')

encrypted = []
for i in range(len(flag_bytes)):
    encrypted.append(flag_bytes[i] ^ key[i % len(key)])

# Print for database_helper.dart
print("final List<int> encryptedFlag = [")
for i in range(0, len(encrypted), 10):
    chunk = encrypted[i:i+10]
    hex_values = ', '.join(f'0x{b:02x}' for b in chunk)
    print(f'  {hex_values},')
print("];")
```

## Supporting Multiple Users

The current implementation only uses ONE encrypted flag. If you want different flags for different users, you have two options:

### Option 1: One Flag, Multiple Users (Current)

All users decrypt the same flag. Just add users to the database:

```bash
cd tools
python3 manage_database.py add user1 pass1
python3 manage_database.py add user2 pass2
python3 manage_database.py add user3 pass3
```

All three users will see the same flag when they login with their respective credentials.

### Option 2: Different Flags per User (Requires Code Changes)

You need to modify the approach:

**A. Store encrypted flags in database:**

```sql
-- Modify table schema
ALTER TABLE credentials ADD COLUMN encrypted_flag TEXT;

-- Add users with different flags
-- (You'd need to generate each encrypted flag separately)
```

**B. Update database_helper.dart:**

```dart
Future<Map<String, dynamic>?> verifyCredentials(String username, String password) async {
  final db = await database;
  
  final List<Map<String, dynamic>> results = await db.query(
    'credentials',
    where: 'username = ? AND password = ?',
    whereArgs: [username, password],
  );

  if (results.isNotEmpty) {
    // Get the encrypted flag from database
    String encryptedFlagStr = results[0]['encrypted_flag'];
    List<int> encryptedFlag = encryptedFlagStr.split(',').map((e) => int.parse(e)).toList();
    
    String decryptedFlag = _decryptFlag(username, password, encryptedFlag);
    return {'flag': decryptedFlag};
  }

  return null;
}
```

## Important Notes

⚠️ **Remember:**
- Each username/password combination produces a UNIQUE encryption key
- If you change username OR password, you MUST regenerate the encrypted flag
- The encrypted flag bytes are stored in `database_helper.dart`, NOT in the database
- After any credential change, run `generate_encrypted_flag.py` again

💡 **Tips:**
- Keep the `tools/` scripts for easy management
- Test decryption before updating the app
- Make backups of `medusa.db` before major changes
- Document your credentials securely

## Troubleshooting

**Problem: "Invalid credentials" even with correct login**
- Verify database has the correct username/password
- Ensure encrypted flag matches the current credentials
- Run `generate_encrypted_flag.py` again with current credentials

**Problem: Decryption produces garbage**
- The encrypted flag doesn't match the username/password
- Regenerate using the correct credentials

**Problem: Database changes don't take effect**
- Delete the app from your device/emulator (to clear app data)
- Or delete app data manually
- The database is copied from assets only on first run

**Solution:** After changing `assets/medusa.db`:
```bash
flutter clean
flutter run
```
